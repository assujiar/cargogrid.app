## 1. Why a new decision, not an edit to the old one

`RGL-414.md` §3 already explains the mechanism this ruling follows: `check-go-decision.ts`
compares `authorizedCommitSha` against the exact commit being built and refuses on any mismatch.
`d48b589` was 150+ commits behind `main`'s head by the time this ruling was written — every one of
those commits closed real backlog items or fixed real gate failures (`RGL-415.md`, `RGL-416.md`,
and the commits either side of them). A go decision that named a stale commit would either block
every real build, or — worse — someone would be tempted to "fix" it by weakening the gate. Neither
is the right answer. The right answer, which this file is, is what `RGL-414.md` §3 predicted: *"A
new deployment needs a new decision. That is the gate working, not a problem to route around."*

## 5. Promotion — what happened, stated plainly

**The promotion has not been performed, and this session cannot perform it** — the same structural
reason `RGL-414.md` §7 recorded, unchanged since:

- `git.deploymentEnabled.main = false` means merging to `main` deliberately does not deploy —
  `RGL-BLK-001`'s fix, working as intended;
- the Vercel tools available here can list, inspect, and read logs, but none can promote a
  deployment or change its target;
- `deploy_to_vercel` exists and accepts `target: "production"`, but using it would upload an
  ad-hoc file tree with no Git provenance, bypassing `check-go-decision.ts` entirely — exactly the
  "routing around a gate" ADR-0027 Part C forbids. Not used, for production, here or anywhere in
  this session.

So the last click is the owner's. Steps are in `docs/runbooks/human-execution-pack.md` §0.1
(promotion) and §0.2 (domain attachment).

**Live post-deploy verification is therefore also outstanding**, for the same reason `RGL-414.md`
§7 recorded: `ssoProtection.deploymentType = "all_except_custom_domains"` on this Vercel project
covers every `*.vercel.app` URL (confirmed via `get_project_deployment_protection`, this session).
Once `app.cargogrid.net` is attached, that domain is exempt and health probes will resolve. The
results — good or bad — get recorded in a follow-up ruling once that happens.
