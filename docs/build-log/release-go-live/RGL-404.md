category. This is not a reclassification of Step 15's own historical ruling (that record is
unchanged, per this ledger's own append-only discipline) — it is this checkpoint's own independent
application of Step 16's own binding severity model to the same, still-unfixed underlying fact,
which Step 15's own ruling never had occasion to test against a production-money-at-stake bar.

Registered `RGL-BLK-009`, Critical, `OPEN`, **not accepted** — full ruling:
`docs/build-log/release-go-live/BLOCKER_LEDGER.md`.

`docs/build-log/release-go-live/BLOCKER_LEDGER.md`.
