squarely that) and outside an autonomous agent's authority to decide unilaterally. Owner: `RGL-404`
(Go/No-Go), the checkpoint with the authority to decide whether this gap blocks promotion or is
formally accepted, consistent with `RGL-400`'s own identical escalation pattern for the missing UAT
