## 4. §36 completeness is uniform; its *form* is not, and that is by design

All 338 structured prompts have a non-empty §36. They use three forms:

| Form | Count | Correct? |
|---|---:|---|
| `EXPLICIT` — names a concrete successor prompt | 174 | Yes |
| `INDEX_DELEGATED` — "only the execution index may release the next dependency-clean … prompt" | 83 | Yes — the phase execution index owns ordering, not the individual prompt |
| `TEMPLATE` — a `{{NEXT_…}}` placeholder the executing agent resolves at runtime | 81 | Yes — these are the reusable-template and per-phase parameterized prompts |

The mixture is not a defect: `BUILD_EXECUTION_PROTOCOL.md` §3.5 records that 166 capability
prompts deliberately delegate release to the execution index, and `CON-015` narrows that clause
rather than removing it. A validator that demanded an explicit successor everywhere would
manufacture 164 false findings.
