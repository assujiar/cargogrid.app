## 4. Finding `FPV-F001` — a ratified decision with no owning prompt

**`RPD-020` (tenant merge/split is an admin-run migration) is carried by no prompt in the
package.** Severity **HIGH** — a future agent executing the package start to finish would never
build it, and nothing in the package would tell them it was missing.

**How it was confirmed, not assumed.** The naive search finds one hit outside the control
documents, in `10-phase-05-advanced-tms-wms/244_ADVANCED_CLAIM_INCIDENT_PROMPT.md`. Reading it
shows the match is *claim record* merge/split ("Merge duplicates while retaining lineage, split
affected items"), an unrelated use of the same words. The two prompts that would plausibly own
tenant merge/split were then read directly:

- `06-phase-01-platform-core/105_TENANT_PROVISIONING_LIFECYCLE_PROMPT.md` §4 — "one canonical
  tenant lifecycle with idempotent provisioning, isolated bootstrap, guarded state transitions
  and auditable recovery". Its single `merge|split` line is "no broad portal screen unless task
  is **split**/authorized" — a scoping sentence, not the capability.
- `06-phase-01-platform-core/106_SUBSCRIPTION_MODULE_FEATURE_ENTITLEMENT_PROMPT.md` §4 —
  entitlements, quotas and effective dates. Not tenant merge/split.

`136_SUPREME_ADMIN_PORTAL_PROMPT.md` was also checked; it does not carry the capability either.

**Disposition:** registered, **not fixed**. Fixing it means authoring a new capability prompt,
which is exactly the "changes what a future agent builds" class that `ADR-0026` forbids Step 17
from applying. Proposed patch is in the gap/risk register.

## 5. Finding `FPV-F002` — RPD-to-prompt traceability is partial, and the split is not arbitrary

Twelve further RPDs are cited by no prompt file: `RPD-002`, `003`, `006`, `007`, `008`, `018`,
`019`, `024`, `026`, `027`, `029`, `039`. Reading each one's statement separates them cleanly
into two groups, and the distinction changes the severity:

**Group A — corporate and commercial-policy facts, correctly absent from prompts (6).** These
are not software requirements and no prompt should carry them: `RPD-002` (CargoGrid owned under
SAIKI Group), `RPD-003` (first production tenant is external), `RPD-006` (PT SAIKI Group is the
legal contracting entity), `RPD-018` (10% first-year referral share), `RPD-027` (launch price
book), `RPD-029` (launch implementation fees). **No finding.** They belong in the decision
register and nowhere else.

**Group B — software-relevant, subject matter genuinely covered, ID not cited (6).** Severity
**MEDIUM**, and it is a *traceability* defect rather than a coverage one:

| RPD | Subject | Covering artifact, verified by reading it |
|---|---|---|
| `RPD-007` | Modular commercial packaging | `106_SUBSCRIPTION_MODULE_FEATURE_ENTITLEMENT_PROMPT.md` |
| `RPD-008` | Subscription pricing across four dimensions | `106_…ENTITLEMENT_PROMPT.md`; also routed by `GAP-017` |
| `RPD-019` | Controlled white-label | 17 prompt files reference white-label; ratified at implementation precision by `ADR-0017` |
| `RPD-024` | WCAG 2.2 AA | 27 prompt files reference WCAG, including the Step 15 accessibility audit |
| `RPD-026` | Ten-suite module catalogue | `03-architecture-and-plan/36_MODULE_DEPENDENCY_MAP_PROMPT.md` |
| `RPD-039` | Search and field security in PostgreSQL/server policy | 6 prompt files; routed by `GAP-003` and `GAP-016` |

**Why this is a real finding and not pedantry.** `GAP-017`'s own closure route names
"RPD-007/008/027/028" as the decisions it discharges. Of those four, `RPD-028` *is* cited by
three Phase 9 prompt files; `RPD-007`, `008` and `027` are cited by none. The package therefore
already traces RPDs into prompts in some places and not others — the inconsistency is internal
to the package's own convention, not a standard this audit invented. An auditor cannot
mechanically prove coverage for the untraced ones; they must re-derive it by topic, as this lane
just did by hand.

**Disposition:** registered, not fixed. Adding RPD citations means editing prompt files, which
stays `FORBIDDEN` under `ADR-0026`.

**Round result:** no defect found in this lane's own work beyond the check-4 error it found and
