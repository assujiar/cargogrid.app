## 4. Non-regression is enforced by three controls, not by prompt text alone

Prompt text asking for regression tests is the weakest of the three controls the repository
actually runs, and this lane checked all three exist:

1. **Tier A automated gates, every prompt** (`BUILD_EXECUTION_PROTOCOL.md` §2.1) — `typecheck`,
   `lint`, `db:test`, the full `node:test` suite, `git:check-paths`, `security:check`. Mechanical
   and non-deferrable: "A Tier A failure is not deferrable."
2. **Tier B taxonomy self-check, every prompt** (§2.2) — the implementing agent walks
   `RECURRING_DEFECT_TAXONOMY.md` §4 against its own diff. This is the control the protocol
   itself calls "the control that makes batching safe".
3. **Tier C adversarial review** (§2.3, §5.4) — four lenses, and a **mandatory propagation
   sweep**: "A finding fixed only at its discovery site is an incomplete fix." The protocol cites
   this repository's own history of single findings spanning 20, 29, 33, 55, 74 and 91 sites.

## 6. What this lane does NOT claim

Coverage here means **the package requires these gates**. It is not a claim that the gates pass
in the CargoGrid runtime. Two facts from Step 16 remain true and unchanged: CI has been red
(`RGL-BLK-005`), and **`UAT_ACCEPTED` was never obtained** — no UAT environment and no named
business acceptor exists, and no agent may simulate one. A package that *requires* a UAT gate is
not a package whose UAT gate has *passed*.
