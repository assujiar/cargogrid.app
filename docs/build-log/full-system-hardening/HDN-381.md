**13.1 Fixed this checkpoint (Tier C fix pass):**

- **`playwright.config.ts` `testMatch` unanchored-regex footgun** (attack-
  surface lens) — the original `/browser-device-compat\.spec\.ts/` pattern
  was a bare substring match, which would also silently scope in a future
  differently-named file (e.g. a hypothetical `-v2` variant). Anchoring it
  correctly required understanding that Playwright's own `testMatch` matcher
  runs against each candidate file's full absolute filesystem path (traced
  to `createFileMatcher`/`collectFilesForProject` in the installed
  `playwright` package's own runner source), not a `testDir`-relative path —
  two intermediate anchoring attempts (`^e2e\/browser-device-compat\.spec\.ts$`,
  then `^browser-device-compat\.spec\.ts$`) both silently zeroed out all 3
  device-project test counts (`pnpm exec playwright test --list` dropped
  from 34 to 22 total) before the correct end-anchored-only form
  (`/\/browser-device-compat\.spec\.ts$/`) was found and verified restoring
  the full 34-test count.
- **`iphone-chrome` Playwright project added** (attack-surface lens,
  completeness) — Lens 3's own live testing manually verified 4 device
