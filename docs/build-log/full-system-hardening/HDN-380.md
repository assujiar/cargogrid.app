## 11. Taxonomy

**`C-30` added** — an e2e/browser harness pointed at a dev-mode server can fail on a
client-hydration timing race that never reproduces under a production build, making a
tooling artifact look like an application defect. Directly evidenced by this
checkpoint's own `HDN-BLK-009` root-cause investigation (§1, §6): the exact same click
against the exact same route resolved instantly under `next start` but hung
indefinitely under `next dev`. Novel enough to warrant its own class — no existing
class (`C-1..C-29`) covers a test-harness/tooling-mode artifact being mistaken for a
shipped-code defect.
