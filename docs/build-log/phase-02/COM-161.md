## 3. Implementation

### 3.1 Scope (disclosed, migration header)

Two concrete, bounded gaps closed — no generic "provenance framework" invented; every prior capability's own hand-rolled jsonb-snapshot/duplicate-fingerprint pattern (`COM-143..160`) is reused, not replaced:

1. **Referential integrity**: `app.opportunities.account_id uuid references app.accounts(id)` added (nullable, indexed), backfilled from any already-populated `account_ref`, and `app.convert_quotation_to_account` re-pointed (via `create or replace function`, the same extension pattern `COM-155` itself used on `app.resolve_commercial_record_ref`) to set both columns going forward. `account_ref` is retained unmodified — additive only, immutable-migrations convention respected.
2. **Visibility timing**: two new advisory, non-blocking, tenant-scoped functions — `app.find_existing_accounts_for_lead` (company-name-only match, the one identifying field a Lead carries) and `app.find_existing_accounts_for_prospect` (reuses `app.find_duplicate_accounts`' own legal_name+tax_id fingerprint match verbatim) — exposing the same canonical-reuse question `app.get_account_conversion_readiness` already answers, at the two earliest points it is answerable. Both mirror `app.find_duplicate_leads`' own established "surface candidates, never silently block capture" discipline exactly. No new override/audit table: the actual "treat as same entity" actions already exist (`app.link_lead_to_existing_prospect`, `COM-144`; `app.convert_quotation_to_account(p_target_account_id=...)`, `COM-155`) and already self-capture a canonical `app.audit_logs` entry.
3. **Reconciliation safety net**: `app.commercial_opportunity_account_ref_drift` (view, `security_invoker=true`, no masking needed) flags any opportunity where the legacy `account_ref` and canonical `account_id` disagree — should be structurally empty from this checkpoint onward, retained as an ongoing brownfield-drift detector, never a mass-rewrite tool (Prompt 161 §19's own "detect/reconcile... never mass-merge or rewrite without approved mapping").
